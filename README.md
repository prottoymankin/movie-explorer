## Movie Explorer

This is a simple project I built to improve my TypeScript skills and gain more practical experience with React and TypeScript.

### Features

- Fetches movie and TV show data from the [TVMaze API](https://www.tvmaze.com/api).
- Implements client-side pagination on the Movies page.
- Includes debounced live search.
- Displays detailed information in a modal.
- Uses React Hot Toast for error notifications.
- Includes loading states and fallback UI for missing data.

### Technologies Used

- React
- TypeScript
- Tailwind CSS
- TVMaze API
- React Hot Toast

### Purpose

The main goal of this project was to strengthen my TypeScript knowledge through hands-on practice while building a simple application.
